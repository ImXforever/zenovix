🛠 Build the entire Zenovix stack — by yourself

This package = the whole project: cloud brain + site widget + every guide. The build order lives on this page.

⏱ Total: ~2 hours 💰 ~$30–40/mo Railway + existing hosting ✅ Result: 5 live surfaces — widget, customer bot, admin bot, TWA, web panel
0 of 9 steps

🗺 The whole project at a glance

  • Brain (AGI 1.6.0) → runs on Railway, auto-deployed from GitHub — smart chat, catalog, orders with real ZX- references, admin web panel, admin bot, Telegram Web App (TWA).
  • Widget (v3.2) → a single JS file on your cPanel site — full WhatsApp-style environment + read-aloud button 🔊 + voice input 🎤 + /track.
  • The site host's role: static file + page only — no heavy load on cPanel.
  • Fallback: if Railway ever goes down, the lightweight backend (the backend/ folder in this package) keeps chat alive on cPanel.
