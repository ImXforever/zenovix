Where zenovix.ae stands today

A technical review of the live site (Sep 10, 2026) — an impressive one-page experience with one structural gap.

📄
One static page, zero sub-pagesThe entire site is a single HTML file served by nginx — no /services, /about, /ar. Great for speed; nothing for a visitor to do but read.
📮
The contact form never sends“Send message” only opens an email draft (mailto:). On most phones and shared office machines — where no mail app is configured — the visitor's message simply disappears.
🗂
Nothing is capturedNo form backend, no database, no API. There is no record of who asked, what they wanted, or when — and no way to follow up.
🌙
The studio sleeps, Dubai is globalVisitors arrive from every timezone. Outside office hours, a prospect who has a question currently has no answer and no trace.
✅ The upside: these are exactly the gaps an AI layer closes — without touching the design, the host, or a single line of the existing site.

How it joins zenovix.ae — zero surgery

The site stays exactly as it is. One file is added, two lines are pasted. Removal is two deletes — the site never knew we were there.

On the site (one-time, ~10 min) 
1. Upload  zenovix-chat.js  →  public_html/js/

2. Paste before </body> of the page:

<script>
  window.ZenovixChat = {
    api:     "https://zenovix-production.up.railway.app/api/chat",
    apiBase: "https://zenovix-production.up.railway.app/api/public"
  };
</script>
<script src="/js/zenovix-chat.js?v=3.2" defer></script>

Full illustrated step-by-step guide (EN) ships with the package — any admin can do it.

Nice touches included
  • Design match is exact — the widget uses the site's own tokens: #0E0A1E background, purple→blue accents
  • One line in the site's EN/AR switch → the chat follows the site language (ZenovixChatAPI.setLang("ar"))
  • A “chat instead” link under the current form catches visitors whose device has no mail app
  • Optional Space Grotesk heading font inside the chat — pixel-level brand fit
  • A “Ask Zenovix” link anywhere on the page: just data-open-chat
