Before you start — three things you need

Read for 5 minutes so everything is clear. In a hurry? Jump to "Quick path".

  • cPanel login details — from your host (usually an address like yourdomain.com/cpanel plus username/password, in your hosting welcome e-mail).
  • This package — unzipped on your computer. The widget file is zenovix-chat.js.
  • ~20 quiet minutes 😌 — nothing to install; everything happens in the browser with copy/paste.

🧭 Decide first — which path? (pick exactly one!)

  • Path 1 — connect to the cloud brain (recommended): the bot's brain (AGI) is already deployed on Railway and the address is zenovix-production.up.railway.app (already pre-filled in every code sample here). You only do section 5 — upload one file + two lines of code. Done! ✨
  • Path 2 — local backend on this cPanel (alternative / fallback): if you were asked to also install the lightweight backend on this host, do sections 1–6 in order. (You need the full dev package — ask your lead/developer.)

⚡ Quick path (2 minutes) — see it first!

The widget works fully even without a backend (demo "SIM" mode). To see it on your site right now:

  1. Upload zenovix-chat.js (inside this package) to public_html/js/ in File Manager (create the js folder if it does not exist).
  2. Put these two lines before </body> in the site template:
<script>window.ZenovixChat = {}; </script>
<script src="/js/zenovix-chat.js" defer></script>
✅ Refresh the page — the purple "Ask Zenovix" button appears bottom-right and you have a full demo chat. Now do sections 1–5 for the real chat.
1

Upload files to the host

Goal: the package unpacked and the backend folder ready — Path 2 only.

🧭 On "Path 1" (cloud brain), this section and sections 2, 3, 4 are not needed — jump straight to section 5.

1-1Log into cPanel

Go to yourdomain.com/cpanel (or the address your host gave) and log in.

💡 cPanel is available in many languages — pick yours at the bottom of the screen. We quote the English item names because they are identical everywhere.

1-2Open File Manager, go Home

Find File Manager (Files section). When it opens, click Home in the left column.

⚠️ Careful: we want Home, not inside public_html. The backend folder should live outside public_html so it is not exposed to the internet directly.

1-3Upload the zip

Click Upload (top of File Manager) and choose the package zip. After it finishes, go back (Go Back link).

If uploading a zip is not possible, upload the frontend and backend folders separately — same result.

1-4Extract

Right-click the zip in Home → Extract → confirm the default path (/home/USERNAME).

You should now have /home/USERNAME/zenovix-chat containing backend and frontend. Delete the zip afterwards.

✅ Check: inside zenovix-chat/backend you should see: app.py, passenger_wsgi.py, knowledge.json, requirements.txt, config.example.json and a static folder.
2

Create the Python app in cPanel — Path 2 only

Goal: give the local backend a home on the web so it can run.

2-1Open: Setup Python App

Type Setup Python App in the cPanel search bar and open it. (Not there? See "No Setup Python App?" in the FAQ below.)

2-2Fill in Create Application

Click Create Application and fill the form exactly like this:

FieldValueNote
Python version3.12 (or the highest available)3.10+ is fine
Application rootzenovix-chat/backendthe folder from section 1 — it suggests as you type
Application URLyourdomain.com/chatpick the domain, type chat in the box (or a subdomain like chat.yourdomain.com)
Application startup filepassenger_wsgi.pyexactly this — the app's entry point
⚠️ Names are case-sensitive: type passenger_wsgi.py exactly.

2-3Click Create

After a few seconds the app page appears with a banner showing your virtualenv info.

2-4Copy the virtualenv command for later

Next to "Enter to the virtual environment…" you will see a command like this. Click it to copy — keep it for section 3:

source /home/USERNAME/virtualenv/zenovix-chat/backend/3.12/bin/activate && cd /home/USERNAME/zenovix-chat/backend

The exact line differs per host — always use the one cPanel shows you, not this sample.

3

Install Flask and start it — Path 2 only

Goal: install the only dependency (flask) and bring the backend alive.

3-1Open Terminal

Back in cPanel, search Terminal and open it (Advanced section). A black command line opens — don't worry, we only paste two lines 😊

No Terminal icon? Some hosts lock it; ask support to enable it, or use the "Run Pip Install" button inside the Setup Python App page: type flask and skip to 3-4.

3-2Activate the virtualenv

Paste the command you copied in 2-4 (Ctrl+Shift+V) and press Enter. If the prompt now starts with (venv) or a path in parentheses — success.

3-3Install flask

Paste this and press Enter:

pip install -r requirements.txt

A few install lines ending with Successfully installed flask…. (That is the only dependency — the project is deliberately lightweight.)

3-4Restart and first test 🎉

Back in Setup Python App, press Restart. Then open in a browser (put in your own domain/path):

https://YOUR-DOMAIN.com/chat/health
✅ Something like {"ok": true, "kb_entries": 13, …}? Congratulations — the local backend is alive! If not, section 7 troubleshooting.
4

Settings (optional but recommended) — Path 2 only

All of this is nice-to-have — the chat works without it; it just gets smarter.

4-1Activate the config file

In File Manager inside zenovix-chat/backend: right-click config.example.json → Rename → config.json. Then right-click → Edit.

KeyWhat it does
allowed_originsif the widget lives on a different domain than this API, add the site domain (fixes CORS)
limit_per_minuteper-visitor message cap per minute (default 10)
log_chatstores conversations in logs/chat.jsonl — keep it on to learn what users ask

After saving config.json, press Restart once (step 3-4).

4-2Connect AI (genius answers)

Without it, the bot answers from the knowledge base (knowledge.json) — fast and free. For open, smart answers add an OpenAI-compatible key (OpenAI, OpenRouter, Groq…) to config.json:

{
  "llm_api_key": "sk-...",
  "llm_base_url": "https://api.openai.com/v1",
  "llm_model": "gpt-4o-mini"
}
💡 Don't worry: if the AI service goes down, the bot falls back to the knowledge base — the chat never breaks.

4-3Feed it your own knowledge

Open knowledge.json with Edit and write your business's answers (hours, address, prices, FAQs…). No restart needed — it is re-read on change.

{
  "company": { "email": "studio@zenovix.com", "phone": "+971 4570 1100" },
  "suggestions": ["What services do you offer?", "I need a price quote"],
  "entries": [
    { "q": ["price", "قیمت"], "a": "Your answer here…", "source": "FAQ" }
  ]
}
5

Install the widget on the site — both paths

Goal: the "Ask Zenovix" button appears on the main site and connects to the brain.

5-1Create the js folder, upload the widget

File Manager → public_html → create a js folder with +Folder if missing → enter it → Upload → upload zenovix-chat.js (inside this package).

The result should be: public_html/js/zenovix-chat.js

5-2Put the connect code on the site

Add these two lines to the site template, before the closing </body> tag:

<script>
  window.ZenovixChat = {
    api:     "https://zenovix-production.up.railway.app/api/chat",
    apiBase: "https://zenovix-production.up.railway.app/api/public"
  };
</script>
<script src="/js/zenovix-chat.js?v=3.2" defer></script>
  • Plain HTML site: open the page file, insert the two lines before </body>, save and upload.
  • WordPress: easiest is the WPCode plugin: install → Add Snippet → HTML type → paste → location: Site Wide Footer → save & activate.
⚠️ The brain address is already set: zenovix-production.up.railway.app. Change it only if the team migrates to a new address. On Path 2 (backend on this host) the addresses become: https://YOUR-DOMAIN.com/chat/api/chat and https://YOUR-DOMAIN.com/chat/api/public
💡 What the two URLs do: api = live chat. apiBase = fully LIVE: real catalog, orders with a real ZX reference, and asking the customer for e-mail. Without apiBase the widget still works, but the shop stays in demo (SIM) mode.

5-3(Recommended) wire site buttons to the chat

Any button or link that should open the chat just needs this attribute:

<a href="#" data-open-chat>Ask Zenovix</a>

From JavaScript: ZenovixChatAPI.open(), .send("hi"), .setLang("fa"), .openCatalog(), .reset()

5-4Customize look and copy (optional)

Inside the same window.ZenovixChat you can add:

window.ZenovixChat = {
  api: "…", apiBase: "…",
  lang: "en",                 /* start language: 21 available */
  theme: "dark",              /* dark | light */
  title: "Zenovix",
  subtitle: "Digital Operations Desk",
  buttonText: "Ask Zenovix",
  sound: true,                /* message pop sound */
  tts: true,                  /* 🔊 read-aloud button */
  stt: true,                  /* 🎤 speech-to-text mic */
  whatsappLink: "https://wa.me/97145701100",
  email: "studio@zenovix.com",
  phone: "+971 4570 1100"
};

Troubleshooting — the rescue table

Problem not listed? First check the app log: Setup Python App → View Log.

SymptomMost likely cause and fix
/health won't open or 404Restart the app. Verify Application root = zenovix-chat/backend and startup file = passenger_wsgi.py. Try the exact URL you created in section 2.
500 errorflask not installed. Redo 3-2 and 3-3 (virtualenv source command, then pip install flask) and Restart.
The chat button doesn't appear at all1) Are the two script lines before </body>? 2) Is /js/zenovix-chat.js the right path? Open it directly in the browser. 3) Hard refresh Ctrl+F5 (browser cache).
Chat opens but says "Network problem"The api URL is wrong or CORS blocks it: add the site domain to allowed_origins in config.json (Path 2) and Restart. Both URLs must be complete with https://.
I see the 🔵 SIM badge (not 🟢 LIVE)apiBase is missing or wrong — recheck step 5-2.
Order gives a "Q-…" reference, not ZXThe request never reached /api/public/enquiry. Usual suspects: wrong apiBase, many rapid tests (10 msgs/min limit — wait a bit), or a 429. Test: open …/api/public/site in the browser; you should see JSON.
429 Too many requestsSecurity limit per IP = 10 messages/minute (Path 2 default). Wait a few minutes or raise limit_per_minute in config.json.
Editing knowledge.json changed nothingThe file must be valid JSON (double quotes, commas). Validate at jsonlint.com. Broken syntax = the old version keeps being used.

Beginner FAQ

I don't have "Setup Python App" in my cPanel 😟
It usually exists on CloudLinux cPanel hosts. Two options:
1) Open a ticket with your host: "please enable Setup Python App for my account".
2) If not possible, the backend folder also runs on free Railway or any small VPS (same structure, zero code changes). Either way, the widget works fully in SIM mode without any backend.
Tip: enable SIM mode first so the site is never empty.
What exactly works without a backend, and what doesn't?
Works: the whole WhatsApp-style chat, menus, demo catalog, orders and quotes (simulated), manager panel, support, 21 languages, the customer's conversation persists.
Doesn't: live smart answers, real lead storage on a server, ZX references, e-mail capture. That's why sections 1–3 matter for Path 2 — and Path 1 gives full parity.
Where is customer data stored? Is it safe?
Path 2: orders/tickets in backend/logs/leads.jsonl, conversations in logs/chat.jsonl — on your own host, nothing leaves it. Path 1: everything lands in the AGI platform's PostgreSQL with full admin tooling. Both include rate limits, message length caps, control-character sanitization, CORS and approved-knowledge-only answers.
How do I change texts and names for my brand?
Name, subtitle, button text and theme: window.ZenovixChat (step 5-4). Bot answers and contact info: knowledge.json (step 4-3) on Path 2, or the admin panel's knowledge/CMS tools on Path 1. No need to touch widget code.
Is HTTPS (the green lock) required?
Yes, absolutely. If the site is https but an api address is http, the browser blocks the connection outright. In cPanel, SSL/TLS Status → Run AutoSSL usually installs a free Let's Encrypt certificate in minutes. Then use https:// everywhere in window.ZenovixChat.
How many languages? How do visitors switch?
21. The user types /lang in the chat and picks from the flag picker; Persian and Arabic become fully right-to-left. The widget's start language is set with lang: "fa" etc. in settings (step 5-4). The bot answers in the selected language.
Testing locally on my computer (no host)?
If you have Python: in the package folder run pip install flask then python3 backend/app.py — the server comes up on http://localhost:5000. Then open frontend/demo.html in a browser; you get the same test environment with ready buttons.
