Install Zenovix Chat on your site

Two steps: upload one file, paste two lines. The chat brain already runs on our servers — nothing else to install.

⏱ ~10 minutes 🧩 cPanel access is all you need 🛡 Zero risk — one static file, removable in seconds
0 of 9 steps

1Log into cPanel and open File Manager

Go to yourdomain.com/cpanel, log in, and open File Manager. Enter the public_html folder.

2Create a folder named js (if it doesn't exist)

Inside public_html, click + Folder and name it exactly js (lowercase). If one already exists, just enter it.

3Upload zenovix-chat.js

Inside the js folder click Upload and choose the file zenovix-chat.js from this package. Wait for 100%.

Final location: public_html/js/zenovix-chat.js

4Copy the embed code below

This is your ready-to-use code — the chat server address is already built in:

<script>
  window.ZenovixChat = {
    api:     "https://zenovix-production.up.railway.app/api/chat",
    apiBase: "https://zenovix-production.up.railway.app/api/public"
  };
</script>
<script src="/js/zenovix-chat.js?v=3.2" defer></script>

5Paste it into the site — before </body>

Regular site: open your page file (e.g. index.html or the footer template), find the closing </body> tag at the very bottom, and paste the code just before it. Save and upload the file back.

WordPress: install the free WPCode plugin → Code Snippets → Add Snippet → type "HTML" → paste the code → Insertion: Site Wide Footer → Save & Activate.

6Refresh and check 🎉

Open your site and press Ctrl+F5. After ~2 seconds a purple "Ask Zenovix" button appears bottom-right.

✅ That's it — the chat is live! Visitors' questions are answered by the Zenovix brain on our servers, with real order references (ZX-…) flowing to the team.

❓ Good to know

Is it safe for the site?
Yes — it's one static JavaScript file, the same class of asset as an analytics snippet. It cannot touch your pages, database or e-mail. Visitor chat data goes to the Zenovix chat server (not stored on your hosting). Removing the two lines removes the widget 100%.
Does it slow the site down?
No — ~120KB, loaded with defer (never blocks the page), and it only appears after the page is ready.
What do visitors get?
A WhatsApp-style chat: smart answers, service catalog with quotes, support tickets with tracking references (ZX-…), 21 languages, read-aloud 🔊 and voice input 🎤. Orders and tickets reach your team instantly with the visitor's e-mail.
HTTPS / the green lock?
Yes, the site must be https (cPanel → SSL/TLS Status → Run AutoSSL gives a free certificate). All URLs in the embed code are already https.
How do we update the widget later?
We send you a new zenovix-chat.js → upload it over the old one in js/ and bump the version in the embed line (?v=3.2 → ?v=3.3). One minute.
